# Screenshots

PNG files in this folder are embedded in the root `README.md` and published on GitHub Pages.

## Files

| File | Screen | Content shown |
|------|--------|---------------|
| `01-pr-input.png` | PR input | Empty state with Pull Request URL field, Start button, and multi-tab bar |
| `02-ai-review.png` | AI review | AI Review dialog (rigor, technology, context, language) over a diff |
| `03-review-workspace.png` | Review workspace | Loaded Bitbucket PR with file list, side-by-side diff, and AI panel |
| `04-comments.png` | Comments | Inline AI finding in diff and draft comments ready to post |
| `05-settings.png` | Settings | Appearance, language, sound, PR updates, and Manage PATs |

## Tips

- **Resolution:** 1440×900 or 1920×1080 works well on GitHub Pages.
- **Format:** PNG preferred for UI captures.
- **Privacy:** Redact tokens, emails, and internal repo names before committing.

After updating images, commit and push to `main` — GitHub Pages updates automatically.
